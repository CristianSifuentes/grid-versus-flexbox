# grid-versus-flexbox
Tutorial code: CSS Grid vs. Flexbox – When to use one or the other

## Run locally

Requires [Node.js](https://nodejs.org/).

```bash
npm install
npm start
```

This opens http://127.0.0.1:5500 with live reload: the browser refreshes automatically when you save `index.html`, `styles.css` or images.

Alternatively, in VS Code install the recommended **Live Server** extension (`ritwickdey.LiveServer`) and click **Go Live** in the status bar.
